# Project: System Monitor
This project's interactive Linux process viewer, similar to htop, displays a dynamically updated list of running processes on a computer.

![system_monitor](https://github.com/1Px-Vision/Vision-Based-Off-Road-Hazard-Detection-for-Freespace-Navigation/blob/main/Project%3A%20System%20Monitor/system_monitor.jpg)

* system.h
* format.cpp (Directory src)
* linux_parser.cpp
* main.cpp
